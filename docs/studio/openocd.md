# OpenOCD and GDB

With a known JTAG pinout, the JTAGulator can act as a Bus Pirate-compatible adapter for [OpenOCD](https://openocd.org), so you can halt the target, read and write memory, flash it and debug it with GDB. The **OpenOCD** panel on the JTAG page (under **Known pinout tools**) does every step.

1. **Enter OpenOCD mode** with the pinout. The mode is stored in EEPROM and survives resets until you exit it.
2. Pick a **target config** (STM32, nRF52, RP2040, ESP32 and others) or none to just probe the chain, and an adapter speed.
3. **Launch OpenOCD.** The app releases the serial port, waits for the JTAGulator to restart, and shows OpenOCD's output. It retries once if the JTAGulator doesn't answer the first handshake.
4. **Start GDB** to debug (see below).
5. When done, **Stop OpenOCD** and **Back to menu**, which leaves OpenOCD mode.

OpenOCD must be installed and on your `PATH` (Linux: your package manager; macOS: `brew install open-ocd`; Windows: the xPack build).

## Saving a config file

**Save .cfg** writes the current settings as a commented OpenOCD configuration, to use outside the app with `openocd -f file.cfg`:

```tcl
# OpenOCD configuration generated by PinHound Studio on 2026-10-20
#
# The JTAGulator must be in OpenOCD mode first (JTAG menu, O), entered with these pins:
#   TDI CH3, TDO CH5, TCK CH2, TMS CH4
# Then close any serial terminal and run:  openocd -f <this file>

adapter driver buspirate
buspirate port /dev/ttyUSB0
buspirate speed normal
transport select jtag
gdb_port 3333
source [find target/stm32f1x.cfg]
```

With no target config, the file declares the scanned chain itself (`jtag newtap`, with each IDCODE as `-expected-id`) when every device's instruction length is known from a loaded BSDL file; otherwise OpenOCD auto-probes the chain. The generated files are checked against OpenOCD 0.12 in CI.

## GDB console

Below the OpenOCD output, **Start GDB** runs `gdb-multiarch`, `arm-none-eabi-gdb` or `gdb` (whichever is installed) connected to OpenOCD's GDB server on port 3333, with an optional ELF file for symbols. Type commands in the box (Up/Down recall history) or use the quick buttons: `monitor reset halt`, `info registers`, `x/16xw $sp`, `bt`, `monitor resume`.

Plain `gdb` only debugs other architectures when it was built with multiarch support (the Arch and Fedora packages are). If no GDB is installed, the panel says what to install.
